# 星隅（Stellarium）

仅供个人使用的工作 + 生活一体化本地应用：今日计划、每日手账与账本、自媒体创作、开发工作、健身与饮食记录。

## 打开方式

- 用 Chrome 或 Edge 打开 `index.html` 即可，无需安装、无需联网。
- 建议在浏览器中「添加到收藏夹/固定标签页」，方便日常使用。

## 功能模块

| 模块 | 说明 |
| --- | --- |
| 首页总览 | 今日计划、快速备忘、各模块摘要、更换壁纸（含可读性蒙版） |
| 今日计划 | 每日任务、优先级/标签/时间段、完成、顺延 |
| 每日手账 | 心情/天气/正文 + 月度预算 + 账本流水 + 报表 |
| 自媒体 | 灵感库、草稿大纲、发布日历、平台账号 |
| 开发工作 | 项目任务、学习积累、问题库 |
| 健身计划 | 周计划、训练记录、身体数据趋势 |
| 饮食计划 | 三餐记录、历史、计划模板 |
| 实用小工具 | 计算器、随机数生成器、单位换算、番茄钟、随机抽签、掷骰子、备忘便签、PDF 合并、PDF 拆分/提取页面、PDF→Word、PDF→PPT |
| 游戏娱乐 | 占位（暂未开发） |
| 数据与设置 | 导出/导入备份、清空数据、主题等设置 |

## 数据存储与备份

- 所有数据保存在当前电脑浏览器本地（IndexedDB），无任何联网请求。
- 刷新、关闭页面、重启浏览器和电脑后数据不丢失。
- ⚠️ 清除浏览器数据会删除全部数据，建议定期到「数据与设置 → 导出备份」下载 JSON 备份文件留存。
- 导入备份会覆盖当前数据；导入前应用会自动把当前数据备份一份在本机。

## 运行测试

本仓库含两层自动化测试（无需额外安装）：

```powershell
# 单元测试（纯逻辑：日期/金额/预算/备份/存储）
node --test "test/unit/*.test.mjs"

# 浏览器端到端测试（Playwright 驱动本机 Edge，覆盖全部模块 UI 与持久化）
node --test "test/browser/*.test.mjs"
```

浏览器测试需要系统装有 Microsoft Edge，并配置 Node 可解析 `playwright`（测试脚本内置指向 Codex 运行时依赖路径）。

## 技术说明

- 纯 HTML + CSS + 原生 JavaScript，无框架、无构建步骤；PDF/文档处理基于本地内置的开源库 pdf-lib、pdf.js、docx、pptxgenjs（MIT/Apache-2.0），全程离线、数据不出本机。
- 存储抽象层：IndexedDB（默认）→ localStorage（兜底）→ memory（测试）。
- 主题：星空暗色（默认）/ 极简浅色，在「数据与设置」中切换。
