# 星隅（Stellarium）交互设计 v0.1

## 1. 全局交互规范

- 所有新增 / 修改 / 删除即时写入本地数据库，无需「保存」按钮；手账正文采用自动保存，并显示「已保存 HH:mm」反馈。
- 删除操作统一二次确认弹窗；「清空所有数据」需要输入「清空」两字才能点击确认。
- 空状态：每个列表 / 页面提供友好空状态（图标 + 文案 + 引导按钮），不出现空白页。
- 操作反馈：统一 Toast 提示（成功 / 失败 /「暂未开发」）。
- 导航：侧边栏当前项高亮；内容区顶部显示模块名 + 主操作按钮。
- 键盘：新增任务 / 记一笔支持回车快速提交；ESC 关闭弹层；弹层打开时焦点落在第一个输入框。
- 数据格式：金额保留两位小数；日期统一 YYYY-MM-DD；金额输入即时过滤非数字。
- 校验：必填项（如任务标题、金额）未填时在表单内红字提示，不弹窗。

## 2. 关键交互流程

### 2.1 今日计划

- 新增任务：点击「+ 新增」→ 弹出面板 → 填写标题（必填）/ 时间 / 优先级 / 标签 / 备注 → 确认 → 列表即时插入，Toast「已添加」。
- 勾选完成：点击勾选框 → 划线动画 → 移入「已完成」分组 → 首页今日计划卡片同步。
- 顺延：点击「未完成任务顺延到明天」→ 确认弹窗 → 今日未完成任务复制到明天并标记「已顺延」→ 今日任务归档为未完成。
- 编辑 / 删除：悬停显示操作按钮；编辑弹窗回填原数据；删除需二次确认。

### 2.2 每日手账

- 记一笔：点击「记一笔」→ 弹层（类型 支出 / 收入、金额、分类、备注，默认今天）→ 确认 → 流水列表插入 → 顶部预算条实时更新。
- 预算状态：已用 ≤ 80% 正常（蓝）、80% ~ 100% 紧张（黄）、超过 100% 超支（红）+ 提示「本月已超支 ¥xx」。
- 手账正文：输入停顿后自动保存，右上角显示「已保存 HH:mm」。
- 月历联动：有手账或记账的日期打点；点击日期 → 切到该日手账并高亮。

### 2.3 自媒体

- 灵感 → 草稿：草稿编辑面板可选「关联灵感」，关联后该灵感状态自动变为「已采用」。
- 发布：草稿状态改为「已发布」并填发布日期 → 发布日历对应日期出现「平台 + 标题」标签。
- 日历交互：月历可翻页；点击有排期的日期 → 弹出当日发布列表；「安排发布」→ 选择日期 + 草稿 → 生成排期，可取消排期。

### 2.4 开发工作

- 项目详情：点击项目卡片 → 进入详情（左上返回按钮）；任务状态四态切换（未开始 / 进行中 / 已完成 / 搁置），点击状态标签循环切换或下拉选择。
- 学习进度：进度条可拖动或 +/- 调整，即时保存。
- 问题库搜索：输入关键字实时过滤标题 / 标签 / 解决方案。

### 2.5 健身计划

- 周计划：点击某天格子 → 弹出当天训练内容编辑 → 保存；「复制本周 → 下周」先确认再复制（覆盖下周已有内容需再次确认）。
- 训练记录：「常用动作」下拉快捷填充动作名，避免重复输入；重量 / 次数支持数字键盘。
- 身体数据：新增记录后折线图即时更新，悬停显示数值点。

### 2.6 饮食计划

- 今日饮食：每餐卡片「+ 记录」→ 弹层输入内容 + 热量 → 保存后卡片显示内容与热量；顶部总热量条实时累加。
- 模板套用：点击「套用到今天」→ 确认 → 将模板内容填入今天对应餐次（已填写的内容覆盖前先提示）。

### 2.7 数据与设置

- 导出：点击导出 → 浏览器下载 JSON 备份文件（包含全部数据 + 导出时间）。
- 导入：选择文件 → 校验格式 → 确认后覆盖导入，导入前自动把当前数据另存为备份。
- 清空：输入「清空」→ 红色确认按钮 → 清空全部数据并回到首页。
- 主题切换：星空暗色（默认）/ 极简浅色，即时生效并记住选择。

## 3. 状态设计

- 任务：未完成 / 已完成 / 已顺延
- 草稿：构思 / 写作中 / 待发布 / 已发布
- 灵感：待用 / 已采用 / 放弃
- 项目任务：未开始 / 进行中 / 已完成 / 搁置
- 预算：正常（≤80%）/ 紧张（80%~100%）/ 超支（>100%）

## 4. 反馈与错误

- 必填项未填 → 表单内红字提示。
- 金额非数字 / 为 0 或负数 → 输入框即时过滤 + 红字提示。
- 数据写入失败 → Toast「保存失败，请重试」。
- 导入文件格式不正确 → Toast「备份文件格式不正确」。
- 点击未开发功能 → Toast「该功能暂未开发，敬请期待」。
